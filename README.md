# WedPlan – Wedding Service Booking Platform

## Project Description
WedPlan is a full-stack wedding service booking platform that helps users discover wedding services, book professional vendors, and manage their wedding-related activities. It provides dedicated dashboards for customers, vendors, and administrators.

## Important Features
- User registration and login.
- Google authentication.
- Role-based dashboards (Customer, Vendor, Admin).
- Browse, search, and filter wedding services.
- Book and manage wedding services.
- Vendor service management (Add, Update, Delete).
- Booking request management.
- Admin user and service management.
- Stripe payment integration.
- Vendor subscription management.
- Responsive user interface.

## Technology Stack
- Next.js
- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Better Auth
- Stripe
- Framer Motion
- Lucide React

## Installation Instructions

**1. Clone the Client Repository**
```bash
git clone https://github.com/nayemmizee-profile/Wedding-Plan.git
```

**2. Clone the Server Repository**
```bash
git clone YOUR_SERVER_REPOSITORY_URL
```

**3. Install Dependencies**

Run this command inside both client and server directories:

```bash
npm install
```

**4. Configure Environment Variables**

Create the required `.env` files in the client and server directories and configure the necessary API, database, authentication, and payment credentials.

## How to Run the Project Locally

**Run the Backend:**
```bash
npm run dev
```

**Run the Frontend:**
```bash
npm run dev
```

Frontend: `http://localhost:3000`

Backend: `http://localhost:9000`
